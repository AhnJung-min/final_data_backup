# 기관 로고 참조 세트 — 수집 대상 목록 (2026-10-21)

포스터 검수의 '기관 로고' 조건에 쓸 로고 참조 세트를 모으기 전에, **어디서 어떤 조건으로 받을 수 있는지** 정리한 목록이다.
이 단계에서는 로고 이미지·압축 파일을 내려받지 않았다. 웹 페이지 HTML과 API 메타데이터만 읽었다.

| 파일 | 내용 |
|---|---|
| `manifest.json` | 대상 292건 전체(필드 설명은 아래) + `summary` |
| `manifest.csv` | 같은 내용을 한 줄에 한 대상으로 펼친 표(UTF-8 BOM, 엑셀용) |
| `summary.json` | 요약 수치만 |

## 대상 (292건)
- 광역 16 + 기초 229: 행정안전부 [지자체 누리집](https://www.mois.go.kr/frt/sub/a04/localGovernment/screen.do) 기준.
  - 2026 개편이 반영돼 있다. 전남광주통합특별시가 생겼고, 인천은 제물포구·영종구·검단구·서해구로 바뀌었다.
  - 제주시·서귀포시는 행정시라 `autonomous: false`로 표시했다.
- 정부상징 1건: 중앙부처는 태극 문양과 기관명을 조합해 쓴다. 우리 데이터에 나온 부처는 `ministry_signatures_in_data`에 적었다.
- 공공기관 9 + 재단 37: 팀 데이터에서 자주 나오는 곳만 골랐다.
  - 출처 데이터: 표준데이터 주최·주관·후원, gold-v2h `organizations`.
  - 선정 기준: (gold 포스터 수×2 + 2026년 이후 표준데이터 건수) ≥ 4, 또는 표준데이터 10건 이상.
- 이 292건이 gold-v2h 포스터의 '이름이 읽힌 로고' 등장 594건 중 **382건(64%)**에 해당한다.
  - 나머지는 의회, 축제위원회, 기업, 빈도가 낮은 기관이다.
  - 의회 로고 등장은 해당 지자체 항목의 `data_frequency.council_*`에 따로 셌다.

## 사람이 확인할 곳
1. **상징물 페이지 미확인 23곳**: 자동 탐색 실패(JS 화면, 접속 대기 화면, 접속 차단)나 수동 확인 실패.
   - 강북구, 송파구, 순천시, 광주 남구, 담양군, 완도군, 해운대구, 수영구, 사상구, 대구 중구, 영종구, 수원시, 시흥시, 군포시, 철원군, 인제군, 양양군, 충청북도, 예산군, 무주군, 상주시, 청도군, 의령군
   - 충청북도: 서버가 스크립트 접속을 끊어, 웹아카이브 사본 값만 '미확인'으로 넣었다.
   - 예산군: 상징물 페이지 본문에 다른 표('귀농 지원사업')가 나온다.
2. **2026 개편 6곳**: 전남광주통합특별시, 인천 제물포·영종·검단·서해구, 전남광주통합특별시교육청.
   - 전남광주통합특별시는 새 CI가 아직 없다. 상징물 페이지는 '콘텐츠 준비중'이고, CI 시안 3개를 두고 시민 선호도 조사 중이며 10월 중 확정 예정이다. 그동안 옛 광주·전남 CI를 함께 쓴다.
   - 옛 전남 상징 페이지는 남아 있다. 옛 광주 상징 페이지는 삭제돼 웹아카이브 주소를 `other_pages`에 넣었다.
   - 교육청은 임시 CI를 2026-12-31까지 쓴다.
3. **협의·승인 필요 16곳**: 위 표 참고. 자동 추정분 17곳도 문구를 다시 확인해야 한다.
4. **원본을 바로 받을 수 없는 곳**: 전남광주통합특별시(준비중), 제주특별자치도·강원랜드(화면 이미지만), 제주시(행정시, 자체 상징물 페이지 없음), 함평축제관광재단(독자 CI 없음, 함평군 표기).
5. **상징물 조례를 못 찾은 곳 45곳**: 대부분 자동 검색 결과가 비어 있는 곳이다.
   - 부산·인천·충북은 도시브랜드 조례가 근거다.
   - 경남은 '경상남도기 등에 관한 조례'가 근거다.
   - 진안(군기 조례), 합천(브랜드 슬로건 조례), 강릉(상표권 사용 조례)은 `related_ordinances`에 참고용으로 남겼다.
6. **이름이 바뀐 기관**:
   - 문경관광공사: 누리집에는 옛 '문경관광진흥공단' CI만 있다.
   - 진주문화예술재단: 진주문화관광재단에 흡수·통합됐다.
   - 백제문화재단(부여): 백제문화제재단과 다른 기관이다.
   - 고성문화관광재단: 경남 기관이다.
   - 포천·영월: '문화재단'에서 '문화관광재단'으로 이름을 바꿨다.
7. **Commons 기 SVG**: 현행으로 보이는 파일의 최신 판은 대부분 2021년이다(126/154).
   - 공식 페이지의 최신 CI와 대조해야 한다.
   - 연도 표기나 'County'가 붙은 옛 기는 `historical: true`로 구분했다.

- Commons 최초 업로드 시각은 380개 파일 중 293개만 받았다(429 응답으로 중단). 최신 판 업로드 시각과 라이선스는 380개 모두 있다.
- 자치법규정보시스템 상세 주소는 `histNo`(개정 차수)가 들어간 현재 판 주소다. 개정되면 바뀔 수 있다.
- 지자체 소속 의회, 군(軍) 부대, 기업 로고는 이번 범위 밖이다.

## 주요 필드 (`manifest.json` → `entries[]`)
- `kind`: sido, sigungu, gov_symbol, public_institution, foundation
- `homepage`: 누리집 주소
- `ci`: 공식 상징물·CI 페이지
  - `page_url`, `other_pages`
  - `formats`, `download`: direct, request, view_only, none, unknown
  - `found_by`: 이 값을 찾은 방법
- `license`: 이용 조건 표시
  - `kogl_type`, `kogl_where`: page 또는 symbol
  - `approval_required`, `terms_quote`, `terms_url`
  - `source`: manual-check 또는 auto
- `dev_use`: 비상업 개발용 판정(`status`, `basis`, `conditions`, `auto`)
- `ordinance`: 상징물 조례(이름, 자치법규정보시스템 주소). `related_ordinances`는 참고용 조례.
- `wikidata`: `P154_logo`, `P94_coat_of_arms`, `P41_flag`, `commons_category`
- `commons_flag_svg[]`: 기 SVG 후보 파일
  - `file_page`, `first_upload`, `latest_version`
  - `license`, `historical`
- `variants[]`: 휘장, 슬로건, 영문, 시그니처, 브랜드, 기, 캐릭터 등 여러 표기
- `data_frequency`: 우리 데이터 등장 수(gold 포스터·로고, 표준데이터)
- `verification.status`:
  - verified = 사람이 확인
  - auto_only = 자동 탐색 결과만 있음
  - unverified = 자동 탐색으로도 찾지 못함
  - manual_failed = 사람이 열어 봤지만 확인하지 못함
- `needs_human`: 사람이 확인할 이유
